How to Open HW3 in IntelliJ IDEA

Follow these steps to open the provided Maven project in IntelliJ IDEA:

  1. Download the project: Download HW3.zip, then extract or unzip it.
  2. Open the project: In IntelliJ IDEA, choose File → Open. Select the extracted HW3 folder—the folder containing pom.xml—and choose Open. Do not create a new IntelliJ project. Open the provided HW3 folder directly.
  3. Load Maven: If IntelliJ displays a Maven notification, choose Load Maven Project and wait for dependency loading and indexing to finish. IntelliJ will recognize the source folders, test folders, and JUnit 4 dependency from pom.xml.
  4. Verify the project: In the Project panel, locate src/main/java/hwk/HW3.java and the tests under src/test/java. Open RunAllTests.java and use the green Run triangle beside the class to run the JUnit 4 suite.

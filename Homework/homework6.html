5. Find a sequence

Part2Problems.java · TODO 5

findIn(int[] input, int[] toFind)

Find the target values in source order. Gaps are allowed; each source position can be used only once. Preserve both arrays and use a private recursive helper.

source [1,2,3,4,5], target [1,3,5] → true
Quick self-check

Predict these: source [2,2,3], target [2,3]; source [2], target [2,2]; two empty arrays.

true, false, true. An empty target is always found. Track how both positions change.

A short void recursion example

Read and predict; this is not another coding requirement.

// Precondition: n >= 0
static void echoSteps(int n) {
    if (n == 0) return;
    System.out.print(n + " ");
    echoSteps(n - 1);
    System.out.print(n + " ");
}

What does echoSteps(2) print?

Check your prediction

2 1 1 2 . The first print happens during descent; the second during return. A void call returns control rather than a computed value.

Optional challenge: numbersGame (ungraded)

Can you reach 1 from a positive integer by subtracting 7 or dividing by 3 when divisible by 3? Explore recursive alternatives. Reaching 1 succeeds; dropping below 1 fails. For example, 15 succeeds and 5 fails.

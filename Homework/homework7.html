Download IntelliJ starter ZIP

Learning objectives

  • Traverse a singly linked list using node references.
  • Maintain first and last references during insertion and removal.
  • Test empty lists, single-node lists, repeated values, and invalid indices.

Start here

  1. Extract the ZIP. In IntelliJ, open the LinkedListBonus folder containing pom.xml. Select JDK 21 and let Maven load.
  2. Open src/main/java/sll/SinglyLinkedList.java. Add your name and help citations.
  3. Implement TODOs 01 through 07, starting with add, then size. Read each method's Javadoc.

The seven operations

  • add(Integer element): append the element.
  • size(): return the number of nodes.
  • insertAtIndex(int index, Integer element): insert at index 0 through size inclusive. Insertion at size appends; invalid indices throw IndexOutOfBoundsException.
  • contains(Integer element): return whether an equal Integer value is present.
  • remove(Integer element): remove the first matching value and return true; return false if absent.
  • indexOf(Integer element): return the first matching index, or -1 if absent.
  • set(int index, Integer element): replace at index 0 through size minus one and return the old value. Invalid indices throw IndexOutOfBoundsException.

Compare Integer values rather than object identities. Invalid-index operations leave the list unchanged. Graded inputs use non-null Integers; null handling is not an additional requirement.

[2, 6] → insertAtIndex(1, 7) → [2, 7, 6]
[2, 7, 6] → set(1, 9) returns 7 → [2, 9, 6]
[2, 9, 6] → remove(2) returns true → [9, 6]

Keep the representation consistent

Use the supplied nodes. Keep package declarations, public signatures, node classes, and supplied methods unchanged. An empty list has both first and last null; a single-node list has both references pointing to the same node. The final node's next reference is null.

Predict before testing

Draw first and last before and after removing the only element. What must change when you next append? Compare your prediction with your implementation.

There is no additional algorithms package or written submission.

Run JUnit tests

  1. Open src/test/java/sllTest/RunAllTests.java.
  2. Right-click inside the file and choose Run 'RunAllTests'.
  3. Read failures, fix the relevant TODO, and rerun. You can also run individual test classes.

Unfinished TODOs initially fail with UnsupportedOperationException. Tests for other operations may also depend on add. Do not edit tests. From the project folder, mvn test runs the same public suite.

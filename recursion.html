Recursion Basics

When to use: solve a problem by solving a smaller version of the same problem.

  1. Define the result. What must this call return?
  2. Choose a base case. Answer the simplest input directly.
  3. Make progress. Shrink a string, advance an index, or reduce a number.
  4. Use the smaller result. Combine it with the current step.

For empty input, common identities are:

GoalEmpty-input resultReason
Count or sum0Adds nothing
Build text""Adds no characters
Multiply1Leaves product unchanged
Find any match (OR)falseNo match exists
All items satisfy a condition (AND)trueNo counterexample exists

Choose the base-case answer from the problem, not just the input type. Counting characters returns an integer, not an empty String.

public int digitSum(int n) { // precondition: n >= 0
    if (n == 0) return 0;
    return n % 10 + digitSum(n / 10);
}
Base case
n == 0 returns 0.
Recursive call
n / 10 removes the last digit.
Return value
Add this digit to the sum returned by the smaller call.

Common error: calling digitSum(n) again leaves the problem unchanged. Even with a base case, that call cannot reach it.

Strings

When to use: inspect the first character and let recursion process the remaining text.

charAt(0) reads the first character; substring(1) creates the remaining string. Check the length before accessing a character. Strings are immutable.

String allStar(String s){
  if (s.length() <= 1) return s; // need lookahead
  return s.charAt(0) + "*" + allStar(s.substring(1));
}
Base case
Length 0 or 1 needs no separator.
Recursive call
Process s.substring(1).
Return value
First character + separator + the remaining result, in that order.

Common errors: forgetting return, reading charAt(0) on an empty string, or using == for text equality. Use equals or isEmpty.

Access neededStop before access when
charAt(0)length == 0
charAt(1)length <= 1
charAt(2)length <= 2

These bounds tell you when access is unsafe; the problem still determines the return value.

Another pattern: remove characters
String noX(String s){
  if (s.isEmpty()) return "";
  char c = s.charAt(0);
  String rest = noX(s.substring(1));
  return (c=='x') ? rest : c + rest;
}
Base case
Empty text returns empty text.
Recursive call
Remove the first character from the recursive input.
Return value
Keep or omit the first character, then use the returned suffix.

Arrays

When to use: process a suffix without copying or changing the array.

The array stays the same. The index advances. Assume a non-null array and a nonnegative starting index. An index at the length represents an empty suffix.

public int sumArray(int[] nums, int index) {
    if (index >= nums.length) return 0;
    return nums[index] + sumArray(nums, index + 1);
}
Base case
Stop at or beyond the array length before reading an element.
Recursive call
Advance index + 1, keeping the array unchanged.
Return value
Add this element to the sum of the remaining suffix.
Elements inspectedStop before access
nums[i]i >= nums.length
nums[i], nums[i+1]i >= nums.length - 1
nums[i], nums[i+1], nums[i+2]i >= nums.length - 2

The last valid index is length - 1. The single-element base case stops at the exhausted index, not the last valid element.

Common error: restarting at zero in each recursive call. That revisits the same suffix forever. Starting at a nonzero index must ignore the earlier prefix.

Neighbor search: array220
boolean array220(int[] nums, int index) {
if (index >= nums.length - 1) {
return false; // base: need a pair (index and index+1)
}

int current = nums[index];
int next = nums[index + 1];
if (next == (long) current * 10) {
return true; // found a valid pair
}

// otherwise, move forward
return array220(nums, index + 1);
}
Base case
Fewer than two remaining elements means no pair.
Recursive call
Try the next adjacent pair.
Return value
Return true when a pair matches; otherwise return the recursive search result.

The long cast prevents integer overflow in the comparison.

ArrayLists: mutating versus preserving

Removing index zero changes the caller’s list and shifts the remaining elements. Use isEmpty() for a shrinking list; for an unchanged list, advance an index and stop at its size. Import java.util.ArrayList for these examples.

int sumList(ArrayList<Integer> list) {
    if (list.isEmpty()) return 0;
    int first = list.remove(0);
    return first + sumList(list);
}
Base case
Empty list returns 0.
Recursive call
Remove the first item, then recurse on the now-shorter list.
Return value
Add the removed value to the recursive sum; the original list is emptied.
String joinWords(ArrayList<String> words) {
    if (words.isEmpty()) return "";
    String first = words.remove(0);
    if (words.isEmpty()) return first;
    return first + " " + joinWords(words);
}
Base case
Empty list returns empty text; after the last removal, return the last word.
Recursive call
Process the shortened list.
Return value
Insert spaces only between word entries, with no extra trailing separator. This example empties the list.
int countOdds(ArrayList<Integer> list, int i) {
    if (i >= list.size()) return 0;
    int count = 0;

    if (list.get(i) % 2 != 0) {
        count++;
    }
    return count + countOdds(list, i + 1);
}
Base case
Index reaches the list size: return 0.
Recursive call
Advance the index without removing elements.
Return value
Add the current odd-number contribution to the suffix count.

Helper Methods

When to use: callers should supply the data while a private helper tracks an index or running result.

An explicit-index method asks its caller where to start. A public wrapper starts at a sensible position, keeping that detail private. The wrapper does not need to call itself.

public int countUppercase(String s) {
    return countUppercaseHelper(s, 0);
}

private int countUppercaseHelper(String s, int index) {
    if (index == s.length()) {
        return 0;
    }
    int count = 0;
    if (Character.isUpperCase(s.charAt(index))) {
    count++;
}
    return count + countUppercaseHelper(s, index + 1);
}
Base case
The helper returns 0 at the end of the string.
Recursive call
The wrapper starts at zero; the helper advances its index.
Return value
Each helper call adds its uppercase contribution to the returned suffix count.

Common error: having the helper call the public wrapper again. That resets its progress. Recursive calls belong in the helper and keep its extra state.

Accumulator example: reverse a string
public String reverse(String s) {
    return reverseHelper(s, "");
}

private String reverseHelper(String s, String soFar) {
    if (s.isEmpty()) {
        return soFar;
    }
    return reverseHelper(s.substring(1), s.charAt(0) + soFar);
}
Base case
Empty remaining string returns the accumulated result.
Recursive call
Move the first character to the front of soFar and shorten the remaining string.
Return value
Return the helper’s answer through every pending call.
Accumulator example: sum digits, including negative integers
public int sumDigits(int n) {
    return sumDigitsHelper(Math.abs((long) n), 0);
}

private int sumDigitsHelper(long n, int sum) {
    if (n == 0) {
        return sum;
    }
    return sumDigitsHelper(n / 10, sum + (int) (n % 10));
}
Base case
No digits remain: return the running sum.
Recursive call
Divide by ten and add the current digit to the accumulator.
Return value
The completed sum travels back through the call stack.

Convert to long before taking the absolute value so Integer.MIN_VALUE works too. Java still creates stack frames for these calls.

Tracing & Debugging

When to use: explain what each call knows, what it waits for, and what it returns.

Each call has its own parameters and local variables. Reaching the base case begins the return journey.

  1. Write the current arguments for each call.
  2. Mark the base case and its answer.
  3. Work upward, substituting each returned value.

Check tiny cases first

Test empty input, one item, several items, and a nonzero array index. Check original contents when mutation is forbidden. This JUnit 4 test assumes the example methods are in the same class:

@org.junit.Test public void checksArraySum() {
    int[] nums = {3, 5};
    org.junit.Assert.assertEquals(0, sumArray(new int[]{}, 0));
    org.junit.Assert.assertEquals(8, sumArray(nums, 0));
    org.junit.Assert.assertEquals(5, sumArray(nums, 1));
    org.junit.Assert.assertEquals(0, sumArray(nums, 2));
    org.junit.Assert.assertArrayEquals(new int[]{3, 5}, nums);
}
Base case
Empty arrays and an exhausted index should return zero.
Recursive call
Nonzero starting indexes check that recursion processes only the suffix.
Return value
Assertions compare the returned sums and confirm the input is unchanged.
Diagnose common failures
  • StackOverflowError: check that a reachable base case exists and every call moves toward it.
  • Index out of bounds: check the base case before accessing a character or array element; account for lookahead.
  • Wrong count or missing text: check how the current contribution combines with the smaller result.
  • Always false or zero: check that recursive results are returned rather than discarded.

In RecursionQuest, run the complete test class after debugging individual quests. The unlock check verifies all five challenges. Passing tests supports correctness; also inspect your recursive progress and absence of loops or streams.

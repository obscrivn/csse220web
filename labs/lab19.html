Step 1: Update a Level File

So far, the level may only contain one ball. Now update the level so it can include a player and multiple balls.

Step 1: Add Score Fields to GameModel

The game now needs to remember how many balls were in the level and how many balls the player has removed.

Add these fields to GameModel: 

private int totalBalls;
private int ballsLost;

totalBalls stores how many balls existed at the start. ballsLost stores how many balls have disappeared.

Step 2: Initialize the Score

After the level is loaded and the balls have been added to the list, initialize the score. 

loadLevel();

totalBalls = balls.size();
ballsLost = 0;

This should happen after loadLevel(), because the model needs to know how many balls were actually created.

Step 3: Update the Score When a Ball Disappears

Find the part of GameModel where the player collides with a ball and the ball is removed from the list.

When a ball is removed, increase ballsLost. 

balls.remove(i);
ballsLost++;

The counter should change at the same time as the game state changes.

Step 4: Add Getter Methods

The fields should stay private. To let the screen display the score, add getter methods to GameModel. 

public int getTotalBalls() {
    return totalBalls;
}

public int getBallsLost() {
    return ballsLost;
}

The model owns the data. Other classes can ask for the data through methods.

Step 5: Draw the Scoreboard

The GameComponent draws what the user sees. Use the getter methods from GameModel to display the score.

Add this near the end of paintComponent: 

g2.drawString("Total Balls: " + model.getTotalBalls(), 30, 60);
g2.drawString("Balls Lost: " + model.getBallsLost(), 30, 100);

Draw the scoreboard after the background so the text is visible.

h3>Step 6: Add Game Over Logic

The game should be over when all balls are gone.

Add this method to GameModel: 

public boolean isGameOver() {
    return balls.isEmpty();
}

The model decides whether the game is over because the model owns the game state.

Step 7: Display Game Over

The GameComponent should draw a message when the game is over. Put this near the end of paintComponent so it appears on top of the game. 

if (model.isGameOver()) {
    g2.drawString("GAME OVER!!!!!", 100, 70);
}

Step 8: Stop Movement After Game Over

Once the game is over, the player should stop moving.

In the timer, update the model only while the game is not over. 

timer = new Timer(30, e -> {
    if (!model.isGameOver()) {
        model.update();
    }

    repaint();
});

Lab 16: Robot Roll Call

Polymorphism in action · 15–20 minutes

Predict how robot references behave, then test your ideas in Java. You will trace existing code; no new methods are needed.

Download the IntelliJ starter ZIP · Print the two-page worksheet

1. Download and open (3 minutes)

  1. Download and extract Lab16.zip. In IntelliJ, choose Open and select the extracted Lab16 folder containing pom.xml. Do not create a new project.
  2. Use JDK 21 and allow Maven to load. Open src/main/java/lab/RobotLab.java. Run RobotLab.main() with its green arrow. The untouched starter prints only End of run.
  3. Read Beacon, Robot, Scout, and Medic. Scout and Medic extend Robot; Robot implements Beacon. Keep the code visible while completing the worksheet.

Class resources: polymorphic tracing

Use these resources to review the rules and the examples we worked through in class:

  • Polymorphic Tracing: rules
  • Walkthrough 1: class examples and explanations
  • Walkthrough 2: class examples and explanations

2. Predict (before every run)

Write your name and section on the worksheet. For each experiment, record exact output (one line per printed line), no output, a compile-time error, or a runtime exception. Keep your original prediction, even if it was wrong.

Use the reference declarations at the top of main(). Do not change them or the class implementations.

3. Test (A1–A4: about 5 minutes)

  1. Find the matching experiment label in RobotLab.java.
  2. After predicting, remove the leading // from that one statement. Leave every other experiment commented.
  3. Run RobotLab.main(). Record the actual result; omit the setup marker End of run.
  4. If the result differs, briefly explain why. Comment the statement again before the next experiment.

Part A: A1 robot.signal();, A2 scout.report();, A3 scout.signal();, A4 medic.report();.

4. Investigate errors (B1–B2 and C1–C2: about 7 minutes)

Continue the same predict → test → record routine, one statement at a time.

  • B1: beacon.signal();
  • B2: test robot.boost(); (B2a), then restore it and separately test ((Medic) scout).signal(); (B2b). Predict and record each trial.
  • C1: ((Scout) robot).boost();
  • C2: ((Scout) medic).boost();

If compilation fails, record the compiler message. Do not choose to run an older successful build. If Java starts and throws an exception, record its name; you do not need the full stack trace. A failed build or exception can prevent End of run from appearing.

Restore each experimental line to a comment before continuing. An intentional error is a result to explain, not code to repair.

5. Submit (2 minutes)

Check that all eight questions are complete, including both B2 trials. Scan or photograph both worksheet pages into one readable PDF and submit it to Lab 16 in Gradescope. Submit only the completed worksheet PDF; no Java project is required.

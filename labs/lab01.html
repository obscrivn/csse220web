Lab Assignment 01

Part 1: Unlock the Lab

Before beginning Lab01, complete the Java Treasure Hunt. This warm-up practices Java data types, operators, conditionals, Strings, and loops.

  • Finish all challenges in the Treasure Hunt.
  • Obtain the completion PDF as proof.
  • Complete this requirement before moving to Part 2.

Part 2: Get the Starter Project

The starter ZIP contains a Java 17 Maven project with Lab01.java, Lab01Tests.java, and the JUnit 5 configuration.

Starter ZIP: Download Lab01_starter.zip

  1. Download the Lab01 starter ZIP using the link above.
  2. Extract or unzip the downloaded file.
  3. Open the extracted Lab01_starter folder in IntelliJ IDEA.
  4. If IntelliJ displays a Maven notification, choose Load Maven Project and wait for the import to finish. IntelliJ will recognize the source and test folders and load JUnit 5 from pom.xml automatically.
  5. In the Project panel, locate:
    • src/main/java/lab/Lab01.java
    • src/test/java/lab/Lab01Tests.java
  6. Open Lab01.java and run it with the green Run triangle.
  7. Open Lab01Tests.java and run it with the green Run triangle to run the JUnit tests.
  8. Use failed tests and their messages to guide your debugging.

Part 3: Code + Test

Complete the methods marked TODO in src/main/java/lab/Lab01.java. Keep the provided method headers unchanged.

This combined lab practices:

  • arithmetic and numeric expressions
  • methods, parameters, and return values
  • Strings and concatenation
  • modulo and boolean expressions
  • if / else if / else and logical OR (||)
  • for loops and accumulation
  • String traversal with charAt()

Testing workflow

  1. Run Lab01.java. Compare the visible output with the expected examples printed by main().
  2. Run Lab01Tests.java. Green tests mean those checks passed. A red test means something still needs attention; read its name and failure message, revise your code, and run the tests again.

Optional challenge: countXX provides extra pattern-scanning practice. It is not graded.

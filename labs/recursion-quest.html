Recursion Quest: Unlock the Portal

Five recursive challenges stand between you and the treasure hunt. Complete the Java methods, test your work, then use your portal code to begin the RecursionQuest and pursue your Recursion collectible card.

Before you start

You have practiced numeric recursion. Now apply the same reasoning to strings and arrays. Review Recursion Tips & Patterns: base cases, string recursion, array indexes, and helper methods.

For every quest: complete the method and run the unit tests. Use recursion, with no loops or streams. Keep arrays unchanged. Assume non-null inputs and indexes from zero through the array length.

Part 1: Complete the starter and unlock the mystery code

Step 1: Open the starter

Download RecursionQuest.zip. Extract it first. In IntelliJ, choose File → Open and select the extracted RecursionQuest folder containing pom.xml. Load the Maven project and use Java 21. Wait for dependencies to load.

Open src/main/java/RecursionPractice.java. Your edits go here. Tests are in src/test/java/RecursionPracticeTest.java. The starter compiles, but its unfinished methods deliberately throw exceptions.

Step 2: String quests

Complete both TODO STEP 2 markers.

  • Quest 1 — countX: count lowercase x characters. For example, countX("xXx") returns 2.
  • Quest 2 — changeXY: replace lowercase x with y, keeping everything else. changeXY("xX") returns "yX".

Predict each method's result for an empty string before coding. What does the first character contribute? What should the smaller call return?

Work in CodingBat, then copy only the working method body into the matching Java method, replacing the exception. Keep the starter's public static signature and parameter name str; do not paste another method inside it.

Hint: choose the return value for this problem

Both methods can shrink the string with substring(1). A counting method returns an integer; a string-building method returns a String. Their base-case return values differ.

Step 3: Array quests

Complete both TODO STEP 3 markers.

  • Quest 3 — array6: report whether a 6 exists at or after index.
  • Quest 4 — array11: count 11s at or after index. Use the array-index patterns in the reference page as needed.

Predict array6(new int[]{6, 2}, 1) and array11(new int[]{11, 2, 11}, 1). The prefix before the starting index must be ignored. Then transfer your CodingBat method bodies as in Step 2.

Hint: the array stays; the index moves

Check your base case before reading nums[index]. When index equals the length, no elements remain. Move the index forward on each recursive call without modifying the array.

Step 4: Build a recursive helper

Quest 5 — countEven: count even integers in the whole array. Zero and negative even integers count. For {0, -2, 3}, predict 2.

  1. At TODO STEP 4a, implement countEven(int[] nums) as a public wrapper that starts the private helper at the beginning.
  2. At TODO STEP 4b, implement countEvenHelper(int[] nums, int index) recursively. Decide its base case, the current element's contribution, and how to combine that with the remaining count.

Keep the helper private. Do not change the array. The public method starts the helper at the beginning of the array.

Step 5: Run the unit tests and obtain your mystery code

  1. Open src/test/java/RecursionPracticeTest.java in IntelliJ.
  2. Click the green arrow beside the class name to run all unit tests.
  3. If a test fails, use its failure message to fix your method, then run the tests again. Keep the supplied tests unchanged.
  4. When all six tests pass, find your mystery code in the IntelliJ Run console. The unlock test checks all five recursion challenges before printing the code.

No reflection or written explanation is required. Continue to Part 2 with your mystery code.

Part 2: Play RecursionQuest

The unlockPortal test repeats every required check and prints the portal message only after they all succeed. Read the Run console for your code, then enter it in Treasure Hunt to begin the RecursionQuest.

  1. Finish Part 1 and run the complete JUnit class. All six tests must be green; copy the mystery code from the IntelliJ Run console. You do not need to edit or configure the portal code.
  2. Open Java Treasure Hunt.
  3. Choose RecursionQuest and use your mystery code to enter. Complete the Treasure Hunt game challenges and pursue your Recursion collectible card.

If RecursionQuest is not yet available in the game, keep your code and completed project ready for the instructor’s launch announcement.

No separate Gradescope submission is required. Keep your completed Java project as a recursion reference. The Treasure Hunt reward is a separate activity.

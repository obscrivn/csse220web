01. JUnit Test Practice

Instructions

In this activity, you will practice writing and running JUnit tests for sorting algorithms using the provided Sort.java class. Download file: Sort.java

Common JUnit Assertions

Assertion Purpose Example
assertEquals() Checks if two single values are equal 
assertEquals(5, score);
assertTrue() Checks if a condition is true 
assertTrue(arr[0] == 0);
assertFalse() Checks if a condition is false 
assertFalse(gameOver);
assertArrayEquals() Checks if two arrays contain the same values 
assertArrayEquals(
    new int[] {0, 2, 3, 5},
    arr
);
assertNotNull() Checks that an object exists 
assertNotNull(player);

What We Did in Class

  • Create a test class named SortTest
  • Use the @Test annotation
  • Test both selection() and insertion()
  • Use assertArrayEquals() to compare arrays
  • Use assertTrue() for simple checks
  • Test edge cases such as empty arrays

Example Patterns from Class

@Test
public void testSelection() {
    int[] arr = {5, 3, 2, 0};

    Sort.selection(arr);

    assertArrayEquals(
        new int[] {0, 2, 3, 5},
        arr
    );
}
@Test
public void testEmptyArray() {
    int[] arr = {};

    Sort.insertion(arr);

    assertArrayEquals(
        new int[] {},
        arr
    );
}

Tips

  • Remember that sorting methods modify the original array.
  • The expected array goes first in assertArrayEquals(expected, actual).
  • Try multiple test cases: sorted arrays, reverse order, duplicates, and empty arrays.
02. Prep (Tier8): 2D World Final Project

Goal

In the previous scaffold, your game loaded objects from a file, moved objects, checked collisions, updated the score, removed objects, and displayed game over.

In this scaffold, you will upgrade the level file into a real 2D grid world. The text file should not only create objects. It should also describe the map.

Big Idea

Your level file can represent the world using symbols: 

***********
*..B...P..*
*..***....*
*.....B...*
***********
Symbol Meaning Suggested Behavior
P Player start Create or position the player here
B Ball / enemy / collectible Add an object to a list
* Wall Store as part of the grid and draw as a square
. Empty space No object here

Use one character per tile. For example, use * for one wall tile, not **.

Step 1: Add a Grid Field to GameModel

In GameModel, add a field for the level map: 

private char[][] grid;

The grid stores the tiles from the level file, such as walls, empty spaces, balls, and the player start location.

Step 2: Read the Level File into a List of Lines

Inside loadLevel, first read the whole file into an ArrayList<String>. Note - remove int row = 0; and row++ from the while loop (from Tier7). 

ArrayList<String> lines = new ArrayList<>();

while (scanner.hasNextLine()) {
    lines.add(scanner.nextLine());
}

We do this because Java needs to know how many rows the grid has before creating the array.

Step 3: Create the Grid After Reading the File

Inside loadLevel, after the file has been read: 

grid = new char[lines.size()][];

The number of rows comes from the number of lines in the file.

Note: Arrays are fixed size, but a 2D array in Java is actually an array of separate row arrays.

Step 4: Convert Each Line into a Grid Row

Still inside loadLevel, loop through the lines: 

for (int row = 0; row < lines.size(); row++)
for (int row = 0; row < lines.size(); row++) {
    String line = lines.get(row);
    grid[row] = line.toCharArray();
}

This changes each string into an array of individual characters.

This transforms: 

"*..P..B*"

into: 

'*' '.' '.' 'P' '.' '.' 'B' '*'

Step 5: Use the Grid to Create Objects

After storing the row in the grid, loop through each column and check the tile. 


for (int col = 0; col < line.length(); col++) {
        char ch = grid[row][col];
// Check the symbol and create objects accordingly (see our example below)
        if (ch == 'P') {
            player = new Player(row, col);
        } else if (ch == 'B') {
            balls.add(new Ball(row, col));
        }

Note: The grid stores the map only. The objects store things that move or interact.

Step 6: Draw Walls Directly from the Grid (Example)

Now that your level is stored inside a char[][] grid, you can use the grid to draw wall tiles.

You do not need a separate Wall class for this tier. The model can draw wall tiles directly from the grid.

This means walls can be drawn directly inside GameModel.draw(...) by checking the grid symbols. Example: 

public void drawOn(Graphics2D g2) {
    for (int row = 0; row < grid.length; row++) {
        for (int col = 0; col < grid[row].length; col++) {
            if (grid[row][col] == '*') {
                g2.fillRect(col * TILE_SIZE, row * TILE_SIZE,
                            TILE_SIZE, TILE_SIZE);
            }
        }
    }
    // Draw enemies and player after walls
}
  • col controls horizontal position (x)
  • row controls vertical position (y)
  • x is calculated as int x = col * TILE_SIZE;
  • y is calculated as int y = row * TILE_SIZE;

Step 7: Use the Grid for Wall Collision

Now before moving the player, you can check whether the next tile is a wall. You can check if (grid[nextRow][nextCol] == '*'). Make sure your player has row, col as fields and getRow, getCol so you know where the player is.

Suggested Game Improvement: Grid-Based Width and Height

Once your game becomes grid-based, the level file should help control the game dimensions.

Instead of relying only on hardcoded values such as: 

WIDTH = 400
HEIGHT = 150

consider calculating the dimensions from the grid itself.

Example helper methods inside GameModel: 

public int getGridWidth() {
    return grid[0].length * TILE_SIZE;
}

public int getGridHeight() {
    return grid.length * TILE_SIZE;
}

Update setPreferredSize in the drawing component after loading the model

Update width and height in painting component for drawing background image. Recall that you have model in the constructor of the drawing component, so you can call the helper methods to get dimensions from the model.

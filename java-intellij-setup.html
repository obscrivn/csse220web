Java + IntelliJ IDEA Setup

1. Before You Begin

This guide is written for a Rose-Hulman Windows 11 Lenovo laptop. Plan for about 20–30 minutes.

  • Connect the laptop to power and to a reliable internet connection.
  • Have the laptop’s administrator credentials available. If Windows blocks an installation and you do not have permission, see Administrator permissions.
  • Close any old IntelliJ projects so the Welcome screen is easy to find.
Use Java 21 LTS. Do not choose “latest,” an early-access release, or Java 25. All CSSE220 examples and assignments use Java 21 LTS.

2. Install IntelliJ IDEA

  1. Open the official IntelliJ IDEA download page.
  2. Download the Windows .exe installer. Use the x64 installer for the standard Rose-Hulman Lenovo laptop.
  3. Open the downloaded installer. If Windows asks whether the installer may make changes, choose Yes.
  4. Keep the default installation location. A desktop shortcut and the Open Folder as Project option are useful but not required.
  5. Finish the installation and launch IntelliJ IDEA.
  6. Accept the license terms if prompted. On the Welcome screen, do not open or import an old project.
Two separate pieces: IntelliJ IDEA is the program where you edit and run code. The Java Development Kit (JDK) contains the Java compiler and runtime. You need both.

3. Install / Configure the Required Java JDK

Let IntelliJ download and configure the JDK. You do not need to edit JAVA_HOME manually.

New Project → Java → JDK → Download JDK

  1. From the Welcome screen, select New Project. If a project is already open, use File → New Project.
  2. Select Java in the left column.
  3. For Location, create or select a CSSE220 course folder instead of using the default IdeaProjects folder. Organize your work as separate project folders: 
    C:\Users\your-username\CSSE220\
├── CSSE220-Setup\
├── Lab01\
├── Homework01\
└── FinalProject\
    For this exercise, the final project path should be C:\Users\your-username\CSSE220\CSSE220-Setup.
  4. Open the JDK menu and select Download JDK.
  5. Set Version to 21. Leave the vendor and installation location at their defaults unless your instructor says otherwise.
  6. Select Download or Select. Wait for IntelliJ to finish before continuing.
Check: The project wizard’s JDK field should now show 21. A longer label such as 21.0.x is correct.
One folder per project: For graded work, use the separate repository supplied by your instructor or GitHub Classroom and clone it into the CSSE220 course folder. Do not put the entire course in one Git repository, and keep course repositories private unless your instructor explicitly says otherwise.

4. Create Your First IntelliJ Java Project

Remain in the New Project window and use these exact settings:

  • Name: CSSE220-Setup
  • Language: Java
  • Build system: IntelliJ
  • JDK: Java 21
  • Add sample code: Off, if this option appears
  • Create Git repository: Off for this setup exercise

Select Create. IntelliJ may spend a minute indexing the project. Wait until its progress indicator finishes.

Know Your IntelliJ Workspace

Project panel

The file tree on the left. Your Java source files belong under src. Open it with Alt+1.

Editor

The large center area where you read and write Java code.

Run button

The green triangle beside a runnable class or its main method.

Run/output window

The panel that opens at the bottom after a run. It shows program output and errors.

Terminal

A command line inside IntelliJ. Open it with View → Tool Windows → Terminal or Alt+F12.

Error indicators

Red underlines or red marks in the scrollbar indicate code IntelliJ cannot compile. Read the message before changing code.

5. Create HelloWorld.java

  1. In the Project panel, expand CSSE220-Setup.
  2. Right-click the src folder and select New → Java Class.
  3. Enter HelloWorld and press Enter. Choose Class if IntelliJ asks for a type.
  4. Replace the editor contents with the code below. Capitalization and punctuation matter.
public class HelloWorld {
    public static void main(String[] args) {
        System.out.println("CSSE220 setup complete!");
    }
}
Check: The file must be named HelloWorld.java, while the class inside it must be named HelloWorld. Both use the same capital H and W.

6. Run the Program

  1. Find the green triangle in the left gutter beside main or HelloWorld.
  2. Select it, then choose Run 'HelloWorld.main()'.
  3. Wait for the Run window to open at the bottom of IntelliJ.

Your Run window may include a long Java command first. The important final lines are:

CSSE220 setup complete!

Process finished with exit code 0
Success: Exit code 0 means the program finished normally.

7. Verify Java and javac

  1. Open View → Tool Windows → Terminal, or press Alt+F12.
  2. At the prompt, enter each command separately and press Enter:
java --version
javac --version

The exact vendor and update number may differ. Confirm that:

  • java --version reports a version beginning with 21, and
  • javac --version reports javac 21 followed by an optional update number.
Why both? java runs compiled programs. javac compiles Java source code. A complete development setup needs both commands.

8. CSSE220 Setup Checklist

Before class, confirm every item:

  • IntelliJ IDEA opens successfully.
  • The CSSE220-Setup project opens.
  • IntelliJ recognizes Java 21 LTS as the project JDK.
  • HelloWorld.java compiles.
  • The program prints CSSE220 setup complete!
  • The program finishes with exit code 0.
  • java --version works and reports Java 21.
  • javac --version works and reports Java 21.
Ready for class: Keep this project. Your instructor may ask you to show its output or use it for a quick check.

9. Troubleshooting

Try the matching fix, then repeat the checklist item that failed.

No JDK appears in IntelliJ

Open File → Project Structure → Project. At SDK, choose Download JDK, select version 21, and wait for the download to finish.

The Java file has many red errors

Wait for indexing to finish. Confirm that the project SDK is Java 21, then compare your code character-for-character with the example above.

The Run button is unavailable

Confirm that HelloWorld.java is inside src, the braces match, and the class contains the exact public static void main(String[] args) line.

The wrong JDK is selected

Open File → Project Structure → Project and change SDK to Java 21. Apply the change, then run the program again.

java works but javac does not

Verify that the project SDK is a Java 21 JDK, not a runtime. Close the current Terminal tab and open a new one so it picks up the project JDK, then retry both commands.

You created a Maven or Gradle project

Leave that project in place and create a new one with File → New Project. Select Java, choose IntelliJ as the build system, and use Java 21.

IntelliJ cannot find the main method

Check spelling and capitalization. The method must be inside the HelloWorld class and must read exactly public static void main(String[] args).

Installation requires administrator permissions

Do not try to bypass the restriction. Use your laptop’s approved software installation process or contact Rose-Hulman EIT. Tell your instructor before class if access is still blocked.

Still stuck? Take a screenshot that includes the full IntelliJ window and the exact error message. Bring it to class or share it using the method your instructor specifies.

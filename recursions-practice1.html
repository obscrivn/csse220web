Reference solutions — check after trying

These course reference implementations are written for this practice page. If a test failed, find the first input where your result differs. Compare your base case and recursive call before replacing any code.

factorial solution
public int factorial(int n) {
    if (n == 1) return 1;
    return n * factorial(n - 1);
}

The smallest product is 1. Multiply n by the product for n − 1.

bunnyEars solution
public int bunnyEars(int bunnies) {
    if (bunnies == 0) return 0;
    return 2 + bunnyEars(bunnies - 1);
}

Remove one bunny, solve the smaller group, then add its two ears.

fibonacci solution
public int fibonacci(int n) {
    if (n == 0) return 0;
    if (n == 1) return 1;
    return fibonacci(n - 1) + fibonacci(n - 2);
}

Both recursive calls move toward a base case. This direct version repeats work; use small inputs for tracing.

bunnyEars2 solution
public int bunnyEars2(int bunnies) {
    if (bunnies == 0) return 0;
    if (bunnies % 2 == 0) {
        return 3 + bunnyEars2(bunnies - 1);
    }
    return 2 + bunnyEars2(bunnies - 1);
}

The current bunny contributes either two or three; the same smaller group is solved in either branch.

triangle solution
public int triangle(int rows) {
    if (rows == 0) return 0;
    return rows + triangle(rows - 1);
}

Add the last row to the total for the smaller triangle.

sumDigits solution
public int sumDigits(int n) {
    if (n < 10) return n;
    return n % 10 + sumDigits(n / 10);
}

A single digit is already its own sum. Otherwise, add the last digit to the sum of the remaining digits.

What to notice

  • The base case answers a small input directly.
  • Every recursive branch moves toward a base case.
  • The return statement combines the smaller answer with the current contribution.
  • Different problems shrink differently: subtract one, subtract two, or remove a digit.

Milestone 0: Pitch Your Idea

🚀 Milestone 0: Pitch Your Idea

Project Idea & Feasibility · 20 points
Due: Sunday, October 18, 2026

Goal: Decide what your team wants to build and describe how someone would use it.

One team submission. No UML, Java code, or GitHub repository is required for this milestone.

Open the Google Docs proposal template

Open the view-only template and choose File → Make a copy. Share the copy with your teammates and fill it in together.

1. Project Identity

Include team members, a working project title, and a category: Game / Interactive App / Simulation / Utility / Other.

2. The Big Idea

In 3–5 sentences, explain what your application does, who would use it and why, and what makes it interesting, useful, or fun.

3. What Can the User Actually Do?

Describe at least three specific user actions and what happens in response to each. Think about buttons, keyboard input, mouse clicks, menus, and changes to application state.

Example: In a dungeon exploration game, the player clicks a room on the map. The application displays the room and updates the player’s current location.

4. What Will the User See?

Describe the main screen: its information, graphics, and controls. Explain how the display changes when the user acts.

Include one simple sketch of the main screen. Hand-drawn or digital is fine; no polished design is needed.

5. Start Small, Dream Bigger

Identify 2–3 essential Core (Must Have) features for a small, complete usable/playable version, and 1–3 Stretch (Nice to Have) features to add only if time permits.

6. Your Biggest Unknown

Name one technical challenge or feature your team does not yet know how to implement, such as graphics, input, data storage, or application logic. You do not need to solve it yet.

Submission

Approximately 1–2 pages of text plus one simple screen sketch. In Google Docs, choose File → Download → PDF Document. Upload one PDF per team to Gradescope and add all team members to the submission.

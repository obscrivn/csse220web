JavaFX Architecture and Events

The objects behind a window

ObjectResponsibility
ApplicationYour entry point. JavaFX calls start(Stage) to build the UI.
StageThe top-level window, including its title.
SceneThe window's content, starting from one root node.
NodeAn item in the scene graph: a control, shape, text, or container.
VBox / HBoxArrange children vertically / horizontally.
PaneHolds drawings at coordinates you choose.
GroupCombines nodes into one view you can move or transform.
Stage
  Scene
    VBox (root)
      Label
      Button
      Pane
        Rectangle

A node has one parent at a time. Create new nodes when you need another independent copy.

Build, attach, show

Label message = new Label("Ready");
Button button = new Button("Say hello");
VBox root = new VBox(12, message, button);
Scene scene = new Scene(root, 400, 300);
stage.setTitle("My JavaFX app");
stage.setScene(scene);
stage.show();

This belongs inside start(Stage stage) of your Application subclass. Use imports from javafx.scene.control, javafx.scene.layout, javafx.scene, and javafx.stage. Creating a node alone does not display it; attach it to the displayed scene graph.

Events happen after setup

button.setOnAction(event -> {
    message.setText("Hello!");
});

This registers a callback. Its body runs when the button is activated, rather than while the handler is registered. JavaFX keeps processing events after start() returns. A button action can come from a mouse click or keyboard activation.

For a shape, setOnMouseClicked(...) responds specifically to mouse input. For example, a handler can call rectangle.setFill(Color.GOLD) to change a Rectangle's color.

State and display are different

An integer field can store the gold total across events. A handler updates that field and then refreshes the Label with setText(). Updating an ordinary field does not automatically change the displayed text.

Predict → activate a control → observe state and display → explain which handler ran. In larger applications, put domain rules in model objects and let handlers call those objects, then refresh the view.

Application lifecycle

main() normally calls launch(args). JavaFX creates the Application and calls start(stage). Closing the last window normally ends the application. start() and UI event handlers run on the JavaFX Application Thread; avoid long-running loops in handlers because they block input and drawing.

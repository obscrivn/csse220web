Three class demo projects

Friday: Shared Scene Demo

On October 16 we will build background layers, a multi-panel layout, and a movable/rotatable Group together, then work on Homework Scenes. This is a class demo, not a separate graded lab.

  1. Add background rectangles before the object.
  2. Arrange heading, controls, drawing, and status using BorderPane.
  3. Rotate around an explicit local pivot.
  4. Translate and reset the complete object.

Prepare with Transforms and Layout. The homework viewer is already provided; no new panel implementation is required for submission.

JavaFX Layout and Multiple Panels

Use layout for panels, coordinates for drawings

A JavaFX panel is usually a Pane or another layout container. A BorderPane can organize the whole window; its center can hold a drawing Pane while its top and sides contain controls. Layout is separate from the coordinate system inside the drawing.

BorderPane (root)
  top: HBox heading / toolbar
  left: VBox buttons
  center: Pane drawing
    Rectangle background
    Group object view
  bottom: Label status

Choose a container

ContainerUse it for
BorderPaneTop, bottom, left, right, center regions of a window.
HBox / VBoxOne row / column of controls; constructor spacing is the gap between children.
GridPaneRows/columns, for example label and input pairs.
StackPaneOverlaid children, centered by default. It can reposition a Group, so it is not the first choice for a fixed-coordinate drawing.
PaneShapes at chosen local coordinates.
GroupA composite object that moves as one unit; it is not a panel-resizing strategy.
TabPaneSeparate views selected by tabs; already supplied by Homework Scenes.

Build a multi-panel window

Pane drawing = new Pane();
drawing.setPrefSize(500, 360);
HBox heading = new HBox(12, new Label("Scene explorer"));
VBox tools = new VBox(10, moveButton, rotateButton);
tools.setPadding(new Insets(12));
BorderPane root = new BorderPane();
root.setTop(heading);
root.setLeft(tools);
root.setCenter(drawing);
root.setBottom(new Label("Ready"));

Assumes moveButton and rotateButton already exist. Import layouts from javafx.scene.layout, Label/Button from javafx.scene.control, and Insets from javafx.geometry. BorderPane arranges one node per region. To place several controls in a region, put them in an HBox/VBox first. Do not add the same control to two containers.

Spacing, dimensions, and resizing

Insets is padding inside a container; HBox/VBox spacing is the gap between children. Preferred size guides layout; it is not a clipping boundary. BorderPane normally gives its center the remaining space. A Pane does not automatically scale all of its drawing coordinates when resized. Fixed-coordinate class demos can use a fixed-size Stage; responsive behavior is a later extension.

For a form, GridPane.add(node,column,row) places a node in a cell. For example grid.add(new Label("Angle"),0,0) and grid.add(angleField,1,0). Use a StackPane for intentional overlays, not when you need a Group's local origin to stay at the drawing origin.

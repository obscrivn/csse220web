JavaFX Setup in IntelliJ

1. Download and open a project

  1. Choose a demo from the Graphics Hub or download your assignment starter.
  2. Extract the ZIP completely. In IntelliJ choose Open and select the extracted folder containing pom.xml. Do not create a new project.
  3. Trust the project if prompted. Choose JDK 21 as Project SDK and allow Maven to load the dependencies. The first import needs internet access.

IntelliJ includes Maven. The supplied POM downloads JavaFX, including native libraries for your operating system; no separate JavaFX SDK or Scene Builder installation is needed.

2. Find Maven

  1. Choose View → Tool Windows → Maven.
  2. If Maven is missing, right-click pom.xml in the Project panel and choose Add as Maven Project. Wait for import.
  3. Use Settings → Build, Execution, Deployment → Build Tools → Maven: select Bundled Maven. Under Maven → Runner, set JRE to Project JDK (21).

You can also press Shift twice, search for Maven, and choose its tool window.

3. Run the application

  1. In the Maven tool window choose Execute Maven Goal.
  2. Select the Maven root for the project you opened.
  3. Enter javafx:run and run it. Do not include mvn in IntelliJ's goal field.
  4. Wait for the window to open. Close the window to end the run.

clean javafx:run also runs the project after deleting previous build output. For normal editing, javafx:run compiles changed source files before launching.

OneDrive note: sometimes clean javafx:run fails when OneDrive or another process locks files in the project's build folder. If the error says Maven cannot delete build output, close the running app and use javafx:run instead. If problems continue, keep a working copy in a local folder outside OneDrive and reopen that copy. Skipping clean does not fix unrelated compile errors.

4. Use the green Run button

  1. Choose Run → Edit Configurations → + → Maven.
  2. Name it, for example, Run JavaFX Demo 1.
  3. Set Working directory to the extracted project folder containing pom.xml.
  4. Set Command line to javafx:run. Apply the configuration.
  5. Select that configuration in the top toolbar, then click its green Run arrow.

Use this saved Maven configuration. The arrow beside the Java main() method may bypass the JavaFX launch settings and report missing runtime components.

5. Switch demos or classes

Each demo has its own folder and POM. Stop the current app, open the next demo folder, and run the Maven configuration whose Working directory points to that folder.

If you create a different Application class in the same project, change the JavaFX plugin's mainClass in pom.xml to its package and class name, such as demo.MyDemo. Do not add .java. Another Maven configuration using the same POM still launches the class named there.

Quick troubleshooting

  • Imports are red: reload Maven and check internet access.
  • Release 21 unsupported: check both Project SDK and Maven Runner JDK.
  • Old demo opens: check Working directory and the POM's mainClass.
  • JavaFX runtime components missing: use the saved Maven run configuration.
  • Window already running: close it or stop the previous run before relaunching.

With Maven installed in a terminal, run mvn javafx:run from the project folder. IntelliJ's bundled Maven does not automatically make mvn available in your terminal.

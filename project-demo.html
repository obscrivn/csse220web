Final Project Hub · Milestone 3

Final Project Demo

Milestone 3 · 60 points. Present your JavaFX application in class on November 13, 2026. No slides needed. An 8–10 minute slot including questions is proposed; follow the instructor’s confirmed slot and duration.

Prepare your walkthrough

  1. Introduce the app. Give its name, purpose, audience, and a short sales pitch.
  2. Run the app. Show its main workflow, required screens, both levels or equivalent content, progress/results, a relevant invalid input or boundary, and restart/repeated use. Assessable functionality must work on screen; describing an unfinished feature does not demonstrate it.
  3. Explain the design briefly. Identify the main classes and one OOP decision. Trace one control → model → display interaction. Put the explicit step-by-step logic workflow in the final report.
  4. Discuss a challenge and highlight. Explain what you tried, how you solved and checked it, and what you would improve.
  5. Describe resources and learning. Identify actual AI tools, Skill Hub guides, starter examples, or other resources used and one example of adaptation and verification. AI and Hub use are optional; explain your actual independent process if you did not use them.
  6. Share the presentation. Every member speaks, identifies their contribution, and is ready to answer questions about their code.

Check the UI before class

A polished game UI has no broken or missing images, broken/clipped/overlapping layout, or missing or hard-to-read text and buttons. Test at presentation size. Arcade games still require the published image sprites; other applications need the designed layout appropriate to their task. Additional decorative effects and stretch features are optional.

Run the final GitHub version with all resources and verified README instructions. Rehearse the order and handoffs. Keep screenshots and known limitations in your report, but screenshots do not substitute for working live functionality.

Demo rubric: 60 points

The five functionality rows total 25; the two technical rows total 10. Full credit requires all evidence in that row. Within a partial-credit range, award more points as more of the stated evidence is accurate and complete. Functionality is assessed through screens, controls, and displayed results. Use the published project specification for the existing scope.

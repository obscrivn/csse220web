Explain the application logic explicitly

The demo shows functionality through the interface. Your report must explain a complete workflow: user action/input → responsible classes and methods → validation and rules/calculations → state changes → displayed result. Include a concrete input/action and expected/actual result, with links or references to the final code. Explain how your implementation works; the testing table separately records evidence that it works.

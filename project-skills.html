Coding Skills Hub

Learn one new technique at a time and add it to your own JavaFX project.

Each skill is a short guided lesson. It explains the idea, shows a few small code fragments, and walks you through building the feature yourself. The first skills build on the Lab 15 Drone Arena code you already finished. Every skill also explains how the same idea works in math solvers, quizzes, simulations, and utilities.

These are not finished solutions. You will not find a complete game or app here. Each guide gives you the concept, a plan, hints, and tests. You write the code and fit it to your own classes. These guides do not change any milestone requirement or grading policy. For those, see Milestone 2 and the Final Project Hub.

How to use a skill

Every skill page uses the same ten sections, so you always know where to look.

Understand

  1. Mission: what you will build and why.
  2. What you already know: the labs and Java ideas you will reuse.
  3. Learn the concept: a short explanation, a diagram, and small code fragments.
  4. Connect to Lab 15: where the idea fits in ArrowApp and SceneToken, or in a non-game app.

Build

  1. Design before coding: decide on state, classes, fields, methods, and who owns what.
  2. Guided implementation: numbered steps with hints, not code to paste.
  3. Test your skill: a normal check, an edge case, and a repeat/reset check.

Grow and record

  1. Extend the skill: one optional harder challenge.
  2. Ask your AI Coach: a prompt you can copy that coaches you instead of doing the work.
  3. Skill Unlocked: three things you should now be able to explain or show.

Then record what you learned in My Skills Acquired.

Before you start any skill: commit your working project on a feature branch, as in the GitHub Desktop walkthrough. If an experiment goes wrong, you can always get back to working code.

Learning with AI coaches and coding agents

Every skill page ends with a prompt you can copy. It works with ChatGPT, Claude, Gemini, Copilot, or another assistant. The prompts ask the AI to coach you: explain the idea, help with one step at a time, and have you test each step. You can still learn every skill without AI, because each page has everything you need.

Using a chat assistant (any browser)

  • A chat cannot see your project. Paste only the classes or methods it needs, and use your real class names.
  • Say what already works, what is missing, and what you expect to happen.
  • Ask for an explanation and a plan before any code.
  • Type the code yourself, run it, and report what actually happened.
  • Never paste passwords, API keys, or other students' information.

Using a coding agent (Copilot agent, Codex, Claude Code)

Optional. You do not need one. Setup routes are in the AI Skills Hub.

  1. Give context: the repository root, the classes involved, and the feature.
  2. Keep the task narrow: one behavior and a list of files it may change.
  3. Plan first: ask it to explain the planned changes before editing.
  4. Review the diff: read every changed file in GitHub Desktop or IntelliJ.
  5. Run and test: use the skill's three tests yourself.
  6. Commit only what you understand and can explain to a teammate.

Course AI policy still applies. Add a Help Citation to files where you got help, and add an entry to AI-LEARNING-LOG.md, as described in the syllabus. You are not graded on how often you use AI. You are responsible for every line you commit and must be able to explain it.
